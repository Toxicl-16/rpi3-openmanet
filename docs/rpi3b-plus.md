# Raspberry Pi 3B+ target

The Raspberry Pi 3B+ target is retained as an archived OpenMANET reference from the earlier firmware publication.

## Hardware and image

- Raspberry Pi 3B+ (`bcm2710`), 64-bit
- Morse Micro MM8108 connected over USB
- Linux 6.6.138
- OpenMANET firmware 1.8.1

The previously published image was named:

```text
openmanet-1.8.1-rpi3-mm8108-usb-squashfs-sysupgrade.img.gz
```

Its recorded SHA-256 was:

```text
3230f4ae45ebc1177d3d89486deaac5d3a5e2cc8594056425064a4a4da5622da
```

That image included the MM8108 USB driver and firmware, `netifd-morse`, the onboard Broadcom Wi-Fi support, and the OpenMANET networking stack. The image itself is not regenerated by the active Pi 5 profile; use a matching archived release if you need this exact Pi 3B+ build.

## Hardware note

Actual boot, USB enumeration, RF operation, and Wi-Fi broadcasting must be validated on a physical Raspberry Pi 3B+ with an MM8108 USB radio.
